# Real Data {#real-data}

*This chapter has not been written yet.*

The same analysis on real data: Ratcliff and Rouder's (1998, Experiment 1) brightness
discrimination task, where three highly practised participants judged whether a patch
was light or dark, with graded brightness and speed and accuracy blocks. Unlike the
simulated data, the true values are unknown, so the chapter relies on the checks from
Chapter \@ref(checking): comparing simulated with observed data, and recovery from
simulated refits.
