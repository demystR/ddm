# Selective Influence {#selective-influence}

*This chapter has not been written yet.*

If the model's parameters mean what Chapter \@ref(the-idea) says they mean, each
manipulation in the task should move "its" parameter and leave the others alone:
coherence should change the drift but not the boundary, and speed-versus-accuracy
instructions should change the boundary but not the drift. This is called **selective
influence**. The chapter fits all of each participant's data, accuracy and speed blocks
together, with models that let the drift, the boundary, or both depend on the
instructions, and compares them with AIC and BIC. It then tests whether drift is
proportional to coherence ($v = k \times c$), which needs one parameter instead of three.
